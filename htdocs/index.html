Use Notes

      

        

          
Unofficial Project

          

            This parser is an independent utility for XML exports and is not affiliated with,
            endorsed by, or supported by 3mensio, Pie Medical Imaging, or Esaote.
          

        

        

          
Clinical Caution

          

            It is intended for research, workflow support, and data extraction only. Validate all
            extracted values against the source report before any clinical use.
          

        

        

          
Privacy Responsibility

          

            Handle patient data carefully and avoid sharing identifiable XML exports, screenshots,
            reports, or derived datasets unless they are properly de-identified and approved.
