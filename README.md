# 3mensioXMLParser


This project is an unofficial parser for XML exports generated by 3mensio-related workflows.
It is not affiliated with, endorsed by, or supported by 3mensio, Pie Medical Imaging, or Esaote.

This software is intended for research, workflow support, and data extraction only.
It is not a medical device and should not be used as the sole basis for clinical decision-making.
Users are responsible for validating extracted values against the source report/export.

Users are solely responsible for ensuring that any data processed, stored, shared, or committed using this software complies with applicable patient privacy requirements, institutional policies, and laws governing protected health information. Do not include patient-identifiable XML exports, screenshots, reports, or derived datasets in public repositories or other shared locations unless they have been properly de-identified and approved for that use.
